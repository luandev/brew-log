# Data Model

## Batch

Required metadata:

- `batch_id`
- `name`
- `type`
- `status`
- `started`

Optional metadata:

- `volume_l`
- `target_abv`
- `actual_abv`
- `tags`

## Supporting files

Each batch may contain:

- `README.md`
- `recipe.md`
- `log.md`
- `schedule.md`
- `tasting.md`
- `media.md`
