# Pages

Public journal routes live in `app/` (Expo Router) and are exported as static HTML.

| Route file | Public URL |
|---|---|
| `app/index.tsx` | `/brew-log/` |
| `app/pages/batches.tsx` | `/brew-log/pages/batches/` |
| `app/pages/active.tsx` | `/brew-log/pages/active/` |
| `app/pages/schedule.tsx` | `/brew-log/pages/schedule/` |
| `app/pages/ciders.tsx` | `/brew-log/pages/ciders/` |
| `app/pages/wines.tsx` | `/brew-log/pages/wines/` |
| `app/pages/status-guide.tsx` | `/brew-log/pages/status-guide/` |
| `app/docs/brewing-notes.tsx` | `/brew-log/docs/brewing-notes/` |
| `app/wiki/index.tsx` | `/brew-log/wiki/` |
| `app/wiki/[slug]/index.tsx` | `/brew-log/wiki/<slug>/` |
| `app/brews/[batchId]/index.tsx` | `/brew-log/brews/<batch_id>/` |
